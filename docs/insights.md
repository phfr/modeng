# Insights (facts learned, with evidence; newest first)
- 2026-11-12 01:20 **Harness parity with modet:** on modet's own candidate set the harness reproduces `modet-U-cov-Lb` exactly (nuAP 0.1775, per-disease max diff 4e-16); raw transfer_jaccard 0.121 there. On the all-gene universe ~18 % of temporal targets are off the STRING network; headline ranks them last and nuAP weights them most (degree 0), so all-gene headline nuAP drops to 0.082 < transfer 0.096. Use `onnet_*` for headline comparisons. (docs/reports/baselines.md)
- 2026-11-12 01:20 **Forward benchmark caveat:** 71 % of 26.09 new genes were already in an ancestor's 25.09 set via a sibling disease; 12 % of raw new genes only appeared through new ontology links (fixed by re-propagating seeds with the 26.09 ontology). Forward is partly an ontology-propagation task.
- 2026-11-12 01:20 **Masking scope matters:** temporal/forward mask only own row + descendants; with modet-style family masking transfer AP drops 0.120 -> 0.084 (temporal), 0.089 -> 0.073 (forward). Holdout: first version leaked through ancestor masking (transfer_onto AUROC 0.29); fixed by re-propagating ancestors.
- 2026-11-12 01:40 **UDT first look (temporal dev, 53 diseases, naive score mixing, `results/exp_udt_temporal_dev.txt`):** virtual-donor families alone are weak (nuAP 0.004-0.012) except **HPO 2021-01 phenotype sets (nuAP 0.064, AP 0.089: disease-derived, temporal-clean)**. Summing all 15 families and adding to transfer: nuAP 0.096 -> 0.100, AP 0.123 -> 0.131, **AUROC 0.68 -> 0.78**: donors mostly re-rank the long tail that transfer cannot reach (zero support), not the head. Naive per-family mixing at 0.2 often HURTS (embedding k-means families -0.005 to -0.01 nuAP): weights must be learned.
- 2026-11-12 02:15 **Learned stacker beats raw transfer (temporal, all-gene universe).** LightGBM over 5 base channels (transfer_jaccard/onto, popularity, degree, RWR) with positives weighted deg^-0.5: nuAP dev OOF 0.106 / confirm 0.132 (transfer_jaccard 0.096 / 0.104); unweighted training gave dev nuAP 0.071 (it learns popularity) -> **positive degree weighting is essential for nuAP** (as in modet F-77/F-93). Adding 15 donor families + 30 view-similarity channels (`stack_bdv_w05`): AP dev 0.084 -> 0.097, confirm 0.093 -> 0.104, AUROC +0.03-0.04, nuAP dev -0.001 / confirm +0.006. On modet's home ground (onnet) stack_bdv confirm nuAP 0.171 vs headline 0.17 (dev 0.154 vs 0.19): comparable, not better yet. HPO-2021 donors and DepMap/ESM-C/GO view similarity are the most used new channels.
- 2026-11-12 02:10 **Biology critic facts (to be verified by implementer H):** GWAS-only arrivals: 0/2,863 have a T0 L2G row for the same disease id, 3.9 % within 500 kb of a T0 L2G gene of the disease, **86 % already L2G >= 0.5 for another trait (base 41.5 %)**, 32 % do not persist to 26.09. ClinVar/curated arrivals: **71 % of genes already in HPO 2021-01 (base 21.7 %)**.
- 2026-11-12 04:20 **Training on past episodes helps nuAP (temporal).** `stackP_base` (LightGBM on 1,786 past episodes 19.04->21.04, 5 base channels, post-fix): nuAP dev 0.119 / confirm 0.134 vs CV-on-53-dev `stack_base_w05` 0.106 / 0.132 and transfer 0.096 / 0.104. Pre-fix `stackP_bdv` (+donors +views): dev 0.127 / confirm 0.151, AP 0.103 / 0.091 (post-fix rerun pending). onnet nuAP of stackP_base dev 0.186 ~ modet headline 0.19 on its own candidate set.
