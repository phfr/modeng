# Data-source sweep 03: cell types, single-cell atlases and foundation models as new witnesses (2026-11-12)

Scope: new evidence channels ("witnesses") from cell-type expression, single-cell atlases and single-cell foundation models (scFMs),
for the modeng stacker (`modeng-v1` = `stack_v3ptr_p0.35`). Nothing was installed or downloaded; local files were inspected read-only.
Web claims carry URL and access date (all accessed 2026-11-12). Search snippets that I could not check against the primary text are marked **[unverified]**.

T0 = OT 21.04 (temporal seeds, inputs should predate 2021-04-30); F0 = OT 25.09 (forward seeds). Leakage classes as in `CLAUDE.md`:
`temporal-clean` (input dated <= seed release), `transductive` (modern input), label-process (forecasts the OT pipeline itself). No
source in this sweep is label-process: expression atlases and scFMs carry no disease-gene labels (the only exception is fine-tuned
heads, see 3.4).

## 0. What is already in the stack, and what we learned
- Views `hpa_sc` (154 HPA cell types), `gtex`, `hpa_tissue`, `ps_*` enter as `vmean_/vmax_` = mean / top-3 cosine of each gene's profile to
  the seeds' profiles (`src/modeng/channels.py:view_sim`). They are mid-ranked in importance (`vmean_hpa_sc` about rank 30 of 140 in
  `results/importance_stack_gate_ctx.tsv`); the R1 red team found that dropping all modern views leaves the result unchanged.
  So **plain "expression similarity to seeds" is saturated**; a new cell-type witness must add a different mechanism.
- Perturbation channels (SC-1, SC-2, CI-01, SC-3/9-lite routing by atlas) are at chance for OT labels (`docs/reports/r1_perturb.md`).
  This is a strong prior against in-silico-perturbation scFM channels (GEARS, STATE, Geneformer deletion).
- SC-3 proper (donor selection by "cellular address") was never tested; only the atlas-routing lite version was.
- **Leakage finding from this sweep:** the `hpa_sc` and `hpa_tissue` views were built from
  `/mnt/msadb/subex/raw/hpa/rna_single_cell_type_current.tsv.zip`, whose member file is dated **2025-12-12 (HPA v25)**, i.e. after F0.
  The manifest calls these views "modern"; they are therefore **transductive on forward too**, not only on temporal. A pre-T0
  replacement is on disk: `/mnt/msadb/subex/raw/hpa_v20/expr_hpa_v20_sc.npy` (18,791 genes x 51 cell types, HPA v20.1, files dated
  2020-11, README with licence CC BY-SA 3.0). Recommended hygiene (cheap): swap `hpa_sc` -> `hpa20_sc` on temporal, HPA v24 (2024-11) or TS v2 on forward.

## 3. Notes
### 3.1 Why CT-ACT is not another expression view
`view_sim` asks "does gene g look like the seeds across all cell types"; broadly expressed housekeeping-like seeds dominate the cosine,
and the signal is diluted across 154 columns. CT-ACT asks "in which cell types are the seeds concentrated beyond chance, and which
genes are specific there", with an explicit null (expression-matched random sets) and an enrichment weight. Strict-a arrivals (GWAS
discoveries) are where cell-type specificity is known to be enriched (LDSC-SEG / scDRS / seismic literature), so this is also the
first single-cell channel with a plausible route to the strict-a stratum. Report strict-a separately.

### 3.2 PoPS single-cell features are the main temporal-clean single-cell resource on disk
The PoPS feature matrices were built from pre-2020 atlases (README in `/mnt/msadb/modet/downloads/pops_features/README.md`).
Column prefixes counted today: `human` 20,947, `mouse` 19,085, `ppi` 8,717 (pathway-naive set; PPI columns should be excluded for this
witness), `ImmGen` 293, `Franke` 153, `GTEx` 68. modet used PoPS only as a GWAS-driven score on a side table; modeng has never used
the feature matrix itself. Mouse clusters need the ortholog map (on disk: `ncbi_gene_orthologs`); PoPS already maps them to human genes.

### 3.3 Foundation-model leakage reasoning
scFMs carry no disease labels, so they cannot leak OT labels directly. They are transductive on temporal because their pretraining
corpora (CELLxGENE 2023-2024, Genecorpus-104M) include post-2021 disease datasets whose cell states were studied because the genes were
already suspected. On forward all listed models predate 25.09 except where noted, so **forward is the fair benchmark for rows 4-9**.
Fine-tuned scFM heads for disease-gene or dosage-sensitivity classification (Geneformer gene classifier) would be trained on label-like
gene lists and must be treated as label-adjacent; use frozen embeddings only.

### 3.4 Install notes (no action taken)
- `bio-sc` has torch 2.14.1+cu130 (sm_120 compatible). Install scFMs in a new venv cloned from it, not into `bio-sc`; pin torch to the
  existing cu128+/cu130 wheel so pip does not pull an older CUDA build; skip `flash-attn` everywhere (scGPT: optional; Geneformer,
  UCE, TranscriptFormer: not required as far as found).
- GPU runs only through `~/biotools/bin/gpu-run --mem <GB> -- <cmd>` in the background; at 12:08 today a 28 GB Boltz job held the GPU.

### 3.5 What would change the ranking
- If the vintage swap (row 3) loses > 0.005, modern expression carried transductive signal and rows 4-7 deserve more weight on forward.
- If CT-ACT passes only on strict-a / GWAS-only arrivals, combine it with MAGMA gene z (seismic-style regression) rather than seeds.
